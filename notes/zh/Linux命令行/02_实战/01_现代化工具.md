# 🌟 现代化工具与技巧

> 2024年推荐安装的 Rust/Go 替代工具，提升 10 倍幸福感。这些工具默认提供了更好的用户体验，让日常命令行工作更加高效、愉悦。

## 1. 现代化替代方案全景对比

### 1.1 核心工具对比表

| 经典命令 | 现代化替代 | 开发语言 | 性能提升 | 核心优势 | 安装命令 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `ls` | **`eza`** / `lsd` | Rust | 相当 | Git状态、图标、树状视图 | `apt install eza` |
| `cat` | **`bat`** | Rust | 相当 | 语法高亮、行号、Git标记 | `apt install bat` |
| `find` | **`fd`** | Rust | **快3-5倍** | 智能忽略、语法简单 | `apt install fd-find` |
| `grep` | **`rg`** (Ripgrep) | Rust | **快5-10倍** | 极速搜索、默认过滤 | `apt install ripgrep` |
| `cd` | **`zoxide`** | Rust | - | 智能跳转、模糊匹配 | `apt install zoxide` |
| `diff` | **`delta`** | Rust | 相当 | 美观的Git diff | `apt install git-delta` |
| `du` | **`dust`** | Rust | 快2-3倍 | 直观磁盘占用图 | `cargo install dust` |
| `top` | **`btop`** | C++ | 相当 | 酷炫UI、鼠标支持 | `apt install btop` |
| `man` | **`tldr`** | Node.js | - | 简明示例代替长文档 | `npm i -g tldr` |
| `curl` | **`httpie`** | Python | - | JSON友好、高亮输出 | `apt install httpie` |

### 1.2 为什么替代？

**🔥 三大核心理由**：

1. **性能飞跃**：Rust 编写的工具（rg, fd, bat）利用多线程和 SIMD 指令集，处理大型项目时速度是传统工具的 **5-10 倍**
   - Ripgrep: 搜索 10GB 代码库只需 2-3 秒（grep 需要 15-20 秒）
   - fd: 遍历百万级文件树比 find 快 3-5 倍

2. **默认即巅峰**：无需记忆复杂参数
   - `rg` 默认忽略 `.git`、`node_modules`、二进制文件
   - `fd` 默认输出带颜色、支持正则
   - `bat` 默认显示行号、语法高亮、自动分页

3. **降低心智负担**：
   - 传统 grep: `grep -r --include="*.js" --exclude-dir=node_modules "pattern" .`
   - 现代 rg: `rg pattern` （自动处理所有边界情况）

## 2. 搜索工具深度对比

### 2.1 ripgrep (rg) vs grep

| 特性 | grep | ripgrep (rg) |
| :--- | :--- | :--- |
| **搜索速度** | 基准 | **快 5-10 倍** |
| **递归搜索** | 需加 `-r` | 默认递归 |
| **忽略文件** | 手动指定 | 自动读取 `.gitignore` |
| **正则支持** | 基础/扩展 | PCRE2 (Perl兼容) |
| **输出格式** | 纯文本 | 彩色高亮 |
| **二进制文件** | 可能乱码 | 自动跳过 |
| **配置文件** | 无 | `~/.ripgreprc` |

**实战对比**：
```bash
# 传统 grep：需要多个参数
$ grep -rn --include="*.js" --exclude-dir=node_modules "console.log" src/

# 现代 ripgrep：一条命令搞定
$ rg "console.log" src/

# 带行号和上下文
$ rg -C 2 "error"  # 显示匹配行前后各2行

# 只显示文件名
$ rg -l "TODO"

# 统计每个文件匹配次数
$ rg --count-matches "FIXME"
```

**性能测试数据**（来源：ripgrep 官方 benchmark）：
```
搜索 Linux 内核代码树 (800MB, 60,000 文件):
- grep -r:          14.2 秒
- rg:                1.8 秒  (快 7.9 倍)
```

### 2.2 fd vs find

| 特性 | find | fd |
| :--- | :--- | :--- |
| **语法复杂度** | 高（`-name`, `-type`） | 低（直接输入模式） |
| **搜索速度** | 基准 | **快 3-5 倍** |
| **颜色输出** | 无 | 默认彩色 |
| **忽略规则** | 手动配置 | 自动 `.gitignore` |
| **正则支持** | 有限 | 完整正则 |
| **执行命令** | `-exec` | `--exec` / `-x` |

**实战对比**：
```bash
# 传统 find
$ find . -name "*.md" -type f -not -path "./node_modules/*"

# 现代 fd
$ fd -e md

# 搜索并批量操作
$ fd -e jpg -x convert {} -resize 50% {.}_small.jpg

# 正则搜索
$ fd "^test.*\.py$"  # 查找以 test 开头的 Python 文件
```

### 2.3 fzf：模糊搜索之王

fzf 是一个通用模糊查找器，可以与任何命令组合使用。

**核心用法**：
```bash
# 1. 历史命令秒搜（Ctrl+R 增强）
# 在 .bashrc/.zshrc 添加：
[ -f ~/.fzf.bash ] && source ~/.fzf.bash

# 2. 文件搜索与预览
$ fzf --preview 'bat --style=numbers --color=always {}'

# 3. 与 vim 组合
$ vim $(fzf)

# 4. 进程管理
$ kill -9 $(ps -ef | fzf | awk '{print $2}')

# 5. 目录跳转
$ cd $(find . -type d | fzf)

# 6. 多选模式
$ fd . | fzf -m  # 按 Tab 多选

# 7. 绑定快捷键
$ export FZF_DEFAULT_OPTS="--bind 'ctrl-j:down,ctrl-k:up'"
```

**预览窗口配置**（强烈推荐）：
```bash
# 在 ~/.bashrc 或 ~/.zshrc 中添加：
export FZF_DEFAULT_OPTS="--preview 'bat --style=numbers --color=always --line-range :500 {}' \
--preview-window=right:60% \
--bind 'ctrl-/:change-preview-window(down|hidden|right:60%)'"
```

## 3. 查看工具对比

### 3.1 bat vs cat

| 特性 | cat | bat |
| :--- | :--- | :--- |
| **语法高亮** | 无 | ✅ 支持 300+ 语言 |
| **行号显示** | 无 | ✅ 默认显示 |
| **Git 集成** | 无 | ✅ 显示修改标记 |
| **自动分页** | 无 | ✅ 长文件自动分页 |
| **多文件** | 连续输出 | 每个文件带标题头 |

**使用示例**：
```bash
# 查看文件（替代 cat）
$ bat file.py

# 显示非打印字符
$ bat -A file.txt

# 并排查看多个文件
$ bat file1.py file2.py

# 与 grep 组合
$ rg "TODO" | bat -l rs  # 指定语言高亮
```

### 3.2 delta vs diff

**delta** 是 Git diff 的美化查看器：

```bash
# 配置 Git 使用 delta
git config --global core.pager delta
git config --global interactive.diffFilter "delta --color-only"
git config --global delta.navigate true
git config --global delta.line-numbers true
git config --global delta.side-by-side true

# 或直接在 ~/.gitconfig 添加：
[core]
    pager = delta
[interactive]
    diffFilter = delta --color-only
[delta]
    navigate = true
    line-numbers = true
    side-by-side = true
    features = decorations
```

**效果对比**：
- 传统 diff：纯文本，难以区分改动
- delta：语法高亮、并排显示、行号、分屏导航

### 3.3 eza/lsd vs ls

**eza**（exa 的继任者）：
```bash
# 基本使用
eza -l          # 详细列表（替代 ls -l）
eza -l --git    # 显示 Git 状态
eza --tree      # 树状视图
eza -T -L 2     # 树状，深度2层

# 推荐别名
alias ls='eza --icons --group-directories-first'
alias ll='eza -la --icons --git'
alias lt='eza --tree --icons'
```

**lsd**（替代方案，功能类似）：
```bash
# 安装
apt install lsd

# 使用
lsd -l          # 详细列表
lsd --tree      # 树状视图

# 配置别名
alias ls='lsd --group-directories-first'
```

## 4. 智能导航工具

### 4.1 zoxide：比 cd 聪明 10 倍

**安装与集成**：
```bash
# 安装
sudo apt install zoxide

# Bash 集成（~/.bashrc）
eval "$(zoxide init bash)"

# Zsh 集成（~/.zshrc）
eval "$(zoxide init zsh)"
```

**核心功能**：
```bash
# 智能跳转（基于访问频率）
$ z proj        # 跳到 /home/user/work/my-super-project
$ z blog        # 跳到 /var/www/sakura-blog

# 交互式选择（配合 fzf）
$ zi            # 模糊搜索历史目录

# 快速回退
$ z -           # 跳回上一个目录

# 查看数据库
$ zoxide query --list  # 显示所有记录的目录
```

**为什么比 autojump/fasd 好**：
- 用 Rust 编写，速度更快
- 自动维护目录数据库，无需手动干预
- 支持模糊匹配，不需要完整路径
- 与 fzf 无缝集成

## 5. 终端增强工具

### 5.1 tmux：终端复用器

tmux 允许你在一个终端窗口中创建多个会话、窗口和面板，是远程开发和长时间任务的神器。

#### 核心概念
```
session (会话)
  └── window (窗口) - 类似浏览器标签
       └── pane (面板) - 分屏显示
```

#### 基本操作
```bash
# 会话管理
$ tmux new -s dev           # 创建名为 dev 的会话
$ tmux ls                   # 列出所有会话
$ tmux attach -t dev        # 连接到 dev 会话
$ tmux kill-session -t dev  # 删除会话
$ tmux new -d -s worker     # 后台创建会话

# 快捷键（先按 Ctrl+b，松开后再按）
# 会话
Ctrl+b d                    # 分离（detach）会话
Ctrl+b s                    # 切换会话

# 窗口
Ctrl+b c                    # 创建新窗口
Ctrl+b w                    # 列出窗口
Ctrl+b n                    # 下一个窗口
Ctrl+b p                    # 上一个窗口
Ctrl+b ,                    # 重命名窗口
Ctrl+b &                    # 关闭窗口

# 面板
Ctrl+b %                    # 垂直分屏
Ctrl+b "                    # 水平分屏
Ctrl+b 方向键               # 切换面板
Ctrl+b z                    # 最大化/还原面板
Ctrl+b x                    # 关闭面板
Ctrl+b !                    # 面板拆分为窗口
Ctrl+b { / }                # 交换面板位置
```

#### 推荐配置（~/.tmux.conf）
```bash
# 启用鼠标支持
set -g mouse on

# 更改前缀键为 Ctrl+a（更符合习惯）
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# 启用 256 色
set -g default-terminal "screen-256color"

# 窗口编号从 1 开始
set -g base-index 1
setw -g pane-base-index 1

# 保持历史滚动
set -g history-limit 50000

# 快速重载配置
bind r source-file ~/.tmux.conf \; display "配置已重载"

# vi 模式复制
setw -g mode-keys vi
bind-key -T copy-mode-vi v send-keys -X begin-selection
bind-key -T copy-mode-vi y send-keys -X copy-selection-and-cancel

# 智能选择复制命令
bind-key -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-selection-and-cancel
```

**应用场景**：
1. **远程开发**：SSH 到服务器后启动 tmux，即使网络断开，任务仍在运行
2. **多任务处理**：左边编辑代码，右边运行测试，底部查看日志
3. **配对编程**：多人连接到同一个 tmux 会话协作

## 6. 终端美化

### 6.1 Starship：跨 Shell 提示符

Starship 是一个轻量、迅速、可定制的终端提示符，支持 Bash、Zsh、Fish 等。

**安装**：
```bash
# 一键安装
curl -sS https://starship.rs/install.sh | sh

# 或者
sudo apt install starship
```

**集成到 Shell**：
```bash
# Bash (~/.bashrc)
eval "$(starship init bash)"

# Zsh (~/.zshrc)
eval "$(starship init zsh)"
```

**配置（~/.config/starship.toml）**：
```toml
# 基础配置
[character]
success_symbol = "[➜](bold green)"
error_symbol = "[✗](bold red)"

# Git 显示
[git_branch]
format = "[$branch]($style) "
style = "bold purple"

[git_status]
format = '([$all_status$ahead_behind]($style) )'
style = "bold red"

# 语言版本
[python]
format = '[${version}](\u2212 )'

[nodejs]
format = '[${version}](\u2212 )'

# 目录路径
[directory]
truncation_length = 3
truncate_to_repo = true
style = "bold cyan"

# 命令执行时间
[cmd_duration]
min_time = 5000  # 超过5秒才显示
format = '[took $duration](bold yellow)'
```

### 6.2 Oh My Zsh：Zsh 框架

**安装**：
```bash
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

**推荐配置（~/.zshrc）**：
```bash
# 主题（如果使用 Starship，设置为 random 或 robbyrussell）
ZSH_THEME="robbyrussell"

# 插件
plugins=(
    git         # Git 别名
    z           # 目录跳转（已被 zoxide 替代）
    zsh-autosuggestions  # 自动建议（需单独安装）
    zsh-syntax-highlighting  # 语法高亮（需单独安装）
    docker      # Docker 补全
    python      # Python 补全
    npm         # npm 补全
)
```

**安装额外插件**：
```bash
# 自动建议
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

# 语法高亮
git clone https://github.com/zsh-users/zsh-syntax-highlighting ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

**实用别名**：
```bash
# 在 ~/.zshrc 中添加
alias cat='bat'
alias ls='eza --icons --group-directories-first'
alias ll='eza -la --icons --git'
alias grep='rg'
alias find='fd'
alias diff='delta'
alias top='btop'
alias cd='z'
```

## 7. 深度组合技巧

工具本身很强，但**组合起来**才是真正的效率怪兽。

### 7.1 经典工作流

```bash
# 1. 快速定位文件并编辑
$ fd config | fzf --preview 'bat {}' | xargs vim

# 2. 搜索代码并查看上下文
$ rg "function main" -C 3 | bat -l rs

# 3. 批量重命名（交互式）
$ fd -e jpg | fzf -m | xargs -I{} mv {} {}/old/

# 4. 查找并杀死进程
$ ps aux | fzf --preview 'echo {}' | awk '{print $2}' | xargs kill

# 5. Git 提交历史搜索
$ git log --oneline | fzf --preview 'git show {1}'
```

### 7.2 Ripgrep 配置文件

每次都打 `--hidden --glob '!node_modules'` 很累？配置默认参数：

1. 创建文件 `~/.ripgreprc`：
   ```text
   --hidden
   --glob=!node_modules/*
   --glob=!.git/*
   --smart-case
   --line-number
   --heading
   ```

2. 在 `~/.bashrc` 中生效：
   ```bash
   export RIPGREP_CONFIG_PATH="$HOME/.ripgreprc"
   ```

### 7.3 fzf 高级绑定

```bash
# 在 ~/.bashrc 或 ~/.zshrc 中配置
export FZF_DEFAULT_OPTS="\
--preview 'bat --style=numbers --color=always {}' \
--preview-window=right:60% \
--bind 'ctrl-j:down,ctrl-k:up' \
--bind 'ctrl-/:change-preview-window(down|hidden|right:60%)' \
--bind 'ctrl-y:execute-silent(echo -n {+} | xclip -selection clipboard)' \
--color=bg+:#363a49,bg:#1d2021,spinner:#b8bb26,hl:#d65d0e \
--color=fg:#ebdbb2,header:#d65d0e,info:#8ec07c,pointer:#b8bb26 \
--color=marker:#b8bb26,fg+:#ebdbb2,prompt:#d65d0e,hl+:#d65d0e"
```

## 8. 安装指南

### 8.1 Ubuntu/Debian

```bash
# 一键安装所有工具
sudo apt update
sudo apt install -y \
    bat \
    eza \
    fd-find \
    ripgrep \
    fzf \
    zoxide \
    btop \
    httpie \
    git-delta

# 创建符号链接（部分工具名称不同）
sudo ln -s /usr/bin/batcat /usr/local/bin/bat
sudo ln -s /usr/bin/fdfind /usr/local/bin/fd
```

### 8.2 macOS (Homebrew)

```bash
brew install \
    bat \
    eza \
    fd \
    ripgrep \
    fzf \
    zoxide \
    btop \
    httpie \
    git-delta \
    tmux \
    starship

# 安装 fzf 快捷键
$(brew --prefix)/opt/fzf/install
```

### 8.3 Arch Linux

```bash
sudo pacman -S \
    bat \
    eza \
    fd \
    ripgrep \
    fzf \
    zoxide \
    btop \
    httpie \
    delta \
    tmux
```

```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

cargo install dust lsd starship
```
